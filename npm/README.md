# plotplot

The stem of the plotplot garden: `plotplot` plants every bed into any harness and proves it
is planted.

```bash
npm install -g plotplot
```

Installing fetches the binary built for this machine from the GitHub release at this
package's version, and refuses it unless its sha256 is the one the package carries. No Rust
toolchain is needed. To build from source instead:

```bash
cargo install --locked --git https://github.com/jahala/plotplot plotplot
```

The source, the documentation and the garden: https://github.com/jahala/plotplot

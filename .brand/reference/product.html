the judge of the diff

Tests still mean what they meant.

pulled before it takes root.

weeder is a gate for code an agent wrote. It reads the diff, refuses dishonest growth, and leaves with an exit code that says whether the change goes through. A static Rust binary, milliseconds, no tokens spent, every finding as SARIF 2.1.0.

Install weeder ↓ View source ↗

why

The builder is the worst judge of the build.

An agent that has just written a change is the worst available judge of it. It will report success, and it has every incentive to reach success by the shortest road: delete the failing test, add a skip, catch the exception and move on. weeder notices them first, deterministically, before a human opens the pull request. It has no model, no prompt and no opinion about style.

what it refuses

  • deleted or weakened tests
  • skips
  • stubs
  • swallowed errors
  • secrets
  • guardrail edits
  • dependency-direction violations

the faces

Five faces on one core

  1. 1

    weeder check

    judges a diff and may block. This is the one wired into hooks and CI.

  2. 2

    weeder scan

    judges the repository as it is and never blocks: rotted docs, dead exports, stale work markers, lagging pins.

  3. 3

    weeder guard

    puts that judgement inside git, through hooks git cannot be talked out of running.

  4. 4

    weeder hook

    answers an agent harness's hook event, so a turn ends against weeder's verdict.

  5. 5

    weeder rules

    prints the catalogue, the level each rule carries, and what it may reach over the network.

exit codes

0clean, or warnings only
2at least one block-level finding
3weeder could not run, and the message says why

Exit 3 is a refusal, not a pass.

allowances

A finding is allowed through on the record and never in silence:

  • Weeder-allow: <RULE> <reason>a trailer on the commit, or
  • weeder-allow <RULE>: <reason>a comment on the line.

Install

Release binaries for linux and macos on x86_64 and aarch64, with a SHA-256 beside each.

target=aarch64-apple-darwin
base=https://github.com/jahala/weeder/releases/latest/download
curl -fsSLO "$base/weeder-$target.tar.gz" -O "$base/weeder-$target.tar.gz.sha256"
shasum -a 256 -c "weeder-$target.tar.gz.sha256"
tar xzf "weeder-$target.tar.gz" weeder
install -m 755 weeder ~/.local/bin/weeder

Then weeder guard install --protect main

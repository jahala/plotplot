the beds

eight tools, one garden

Each tool does one thing well. They share one palette, one voice and one structure, and you can use one or grow the whole plot.

  1. ARow A, plan

    what should be built, and what does done mean

    • 01 tendfeature mapping Maps and narrates the work across sessions, so the next session doesn't start blind. soon

  2. BRow B, read

    how the agent reads code, design and voice

    • 02 tilthcode intelligence An AST-aware map of your codebase, so agents read your code instead of grepping it. live
    • 03 petalsbrand intelligence Turns your brand into files agents read before they generate, and audits what they produce. soon

  3. CRow C, run

    how one unit runs, how many run gated, how workers talk

    • 04 umbelorchestration Fans many agent CLIs out from one stem, so Claude Code, Codex and Gemini work together in tmux. live
    • 05 pleachthe conductor Conducts a plan of agent work in isolated git worktrees, and ships only the nodes its gates have verified. live
    • 06 pollenpeer messaging A mailbox per agent, so one can ask another and use the answer, while a human decides which strangers get in. live

  4. DRow D, judge

    is the diff honest, and did any of it help

    • 07 copecathe yardstick Measures the expected dollar cost per correct answer, so agents, MCP servers and harness changes compare on one number. live
    • 08 weederthe judge Reads an agent's diff and refuses deleted tests, stubs and secrets before they land, with no model in the loop. live

why a garden

good work is grown, not rushed

  1. 1
    → pace

    Grown, not generated

    The tools are made for the pace of tending. A change lands when a check proves it, and the map remembers what was tried.

  2. 2
    → plain text

    Files, not dashboards

    Everything is plain text an agent can read and a human can diff. It lives in your repo, with no server to run.

  3. 3
    → exit codes

    Tools that compose

    They compose through files and exit codes, so any one of them works alone and any two work together.
